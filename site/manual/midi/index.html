Invite another instrument.

A fixed map for the two currents. MIDI channel 1 controls Loop A; channel 2 controls Loop B.

Choose the connection.

Follow an external clock.

  1. Hold HOME, turn SELECT to Settings, then press SEL.
  2. Turn knob 1 MIDI CLOCK to USB or TRS, matching your clock connection. OFF uses ReVo’s internal BPM.
  3. Enable MIDI clock output on the sending instrument or DAW. Keep that clock running while you play.
  4. Return to Atolls. Press EDIT again to open Sync, choose Clock, then set the loop’s Division. Use ALGO to configure the other loop independently.

Clock and performance control are independent. Knob 2 MIDI CONTROL selects USB, TRS or BOTH for incoming notes and CCs. Leave it OFF if you only want external timing.

Notes · Control changes

MIDI Timing Clock runs at 24 pulses per quarter note. Selecting USB or TRS makes that input the timing source; the sender must supply clock. Clock selection does not turn a loop’s Play on. Use note 59 for loop transport; this map does not assign MIDI Start/Stop messages to the loops.

Notes.

The same note map applies on channels 1 and 2. Note numbers are authoritative: octave labels can differ between MIDI applications. For Fragments, Note On with velocity zero acts as Note Off. These incoming MIDI notes use the same function order on both channels, even though the two physical keyboard banks have different black-key positions.

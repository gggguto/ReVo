BIOMA / MIDI REFERENCE / BUILD 2026110608

Let the island listen.

Play Wind from another keyboard, shape the inhabitants, and guide their movement without leaving your instrument.

This map requires ReVo build 2026110608 or later. Earlier builds support Bioma MIDI Clock only.

↖ Back to Bioma Atolls MIDI map ↗

Choose the connection.

  1. Hold HOME, choose Settings with SELECT, then press SEL.
  2. Set 2 MIDI CONTROL to USB, TRS or BOTH for notes and CCs. It starts OFF.
  3. For external timing, separately set 1 MIDI CLOCK to USB or TRS and enable clock output on your other instrument. Leave Clock OFF to use Bioma’s internal BPM.

Clock and control can use different connections. MIDI Clock uses 24 pulses per quarter note. The sender must supply a running clock; selecting it does not start Bioma. MIDI Start resets clock phase; note 36 toggles Bioma’s transport.

Play Wind.

Use MIDI channel 1. Notes 53–79 match the 27 physical Wind keys, from F3 to G5 (MIDI note numbers are authoritative). Wind follows the current Chromatic, Scale or Chords mode, key, scale and octave settings, within Wind’s existing voice limit. Notes outside this range are ignored; velocity above zero triggers a key without changing its level.

ChannelMessageAction
1Notes 53–79Note On plays a Wind key. Note Off or Note On velocity 0 releases it, following Release. Drift Hold retains the chord when enabled.
1Note 36Toggle Bioma Play/Stop on each Note On with velocity above zero. Note Off does not toggle. Stop also clears Drift Hold.
1CC123, any valueRelease MIDI-held Wind keys from the sending port. Physical holds and Drift Hold remain independent.

USB and TRS keep separate held-key state. Releasing a note on one connection does not release the same key held on the other connection or physical keyboard. Disable Drift Hold to release a chord retained by Hold.

Shape the island.

CC numbers repeat across channels. Choose the channel first. Continuous controls scale values 0–127 to the stated range. Switches use the 64 threshold. Enumerated choices use the literal index shown, with higher values clamped to the final choice. Controls work from any page and do not navigate the display.
